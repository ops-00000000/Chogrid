# Chogrid - Помощник в принятии решений при покупках

Chogrid - это веб-приложение с интерактивными таблицами, которые помогают пользователям принимать обоснованные решения о покупках. Система позволяет создавать таблицы с произвольными критериями оценки товаров и автоматически рассчитывает их полезность на основе введенных оценок и весовых коэффициентов.

## Функциональность

- Регистрация и авторизация пользователей
- Создание, редактирование и удаление таблиц
- Добавление произвольных колонок с весовыми коэффициентами
- Автоматический расчет полезности объектов на основе оценок и весов
- Возможность публикации таблиц для общего доступа
- Сортировка и фильтрация данных в таблицах

## Технологический стек

### Серверная часть (Backend)
- Node.js
- Express.js
- MongoDB (с Mongoose)
- JWT для аутентификации

### Клиентская часть (Frontend)
- React.js
- Material UI для компонентов интерфейса
- React Router для навигации
- Axios для API-запросов

## Установка и запуск

### Предварительные требования
- Node.js (версия 14.x или выше)
- MongoDB (локально или в облаке)

### Установка и запуск сервера
```bash
# Переход в директорию сервера
cd server

# Установка зависимостей
npm install

# Запуск сервера в режиме разработки
npm run dev
```

### Установка и запуск клиента
```bash
# Переход в директорию клиента
cd client

# Установка зависимостей
npm install

# Запуск клиента в режиме разработки
npm start
```

## Структура проекта

### Серверная часть
- `server/src/controllers/` - контроллеры для обработки запросов
- `server/src/models/` - модели данных (Mongoose)
- `server/src/routes/` - определение маршрутов API
- `server/src/middleware/` - промежуточные обработчики (middleware)
- `server/src/config/` - конфигурация приложения
- `server/src/utils/` - вспомогательные функции

### Клиентская часть
- `client/src/components/` - компоненты React
- `client/src/pages/` - страницы приложения
- `client/src/services/` - сервисы для работы с API
- `client/src/utils/` - вспомогательные функции
- `client/src/styles/` - стили приложения

## Структура базы данных

### Пользователи (Users)
- Имя
- Email
- Хешированный пароль
- Дата создания
- Токен для сброса пароля (опционально)

### Таблицы (Tables)
- Название
- Описание
- Пользователь (владелец)
- Статус публикации (публичная/частная)
- Колонки (массив пользовательских колонок с весами)
- Объекты (массив строк таблицы с оценками и рассчитанной полезностью)
- Даты создания и обновления
